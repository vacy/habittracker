## Zweck & Zielgruppe:
	- Wir glauben echte Persönlichkeitsentwicklung läuft stärker über Kontinuität als über Intensität. Das heißt Gewohnheiten sind starker Treiber für den persönlichen Fortschritt und haben einen nachhaltigeren Effekt als das Abarbeiten von immer neuen Todos. Die App soll helfen den Weg zu visualisieren und zu unterstreichen wie stark ein Momentum hilft mit den eigenen Zielen schrittzuhalten.
	- Die App dient allen Menschen als Unterstützung zu verstehen wie Kontinuität und Regelmäßigkeit ein starker Hebel sind. Sie legt also einen Fokus auf psychische Gesundheit und Menschen die rastlos von Todo zu Todo hetzen anstatt mit Fokus an einer Aufgabe zu arbeiten.
## Art der App
Habittracker zur Visualisierung von Fortschritten durch Kontinuität

## Techstack:
### Frontend:
	- React
	- React Redux
	- Redux Saga
	- React Router
	- Design Framework: Bootstrap React
	- Cookies zur Speicherung von Sitzungsdaten.
	- Diagramme für Kalender und Linecharts: https://nivo.rocks/
### Backend:
	- Node.js
	- Express
	- DB: MySQL
	- JSON Web Tokens (JWT) für Authentifizierung
