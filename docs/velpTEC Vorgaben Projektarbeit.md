# Aufgabenstellung
## Ausgangssituation:
Unternehmen "WebTech Solutions"
### Auftrag
Innovative Webapp Kunden "HealthifyMe", Firma im Gesundheits- und Fitnessbereich
### Umfang
Dein Projektteam besteht aus mehreren Entwicklern, und du bist für die Konzeption, Entwicklung und Dokumentation der Webapp verantwortlich. Am Ende des Projekts musst
du eine ausführliche Präsentation der Webapp erstellen.

# Aufgaben
## 1. Konzeption der Webapp
- [ ] Definiere den Zweck und die Zielgruppe der Webapp.
- [ ] Bestimme, welche Art von Webapp es sein soll (z.B. Tracking-
Tool, Informationsportal).
- [ ] Erstelle einen Papierprototyp oder nutze Tools wie Adobe XD
oder Pencil für das Design.
- [ ] Liste die benötigten Technologien auf.
## 2. Vorstellung des Proposals
- [ ] Dokumentiere dein Konzept schriftlich und formuliere es als E-Mail,
die an deinen fiktiven Projektleiter adressiert ist. Stelle sicher, dass das Konzept detailliert genug ist, um als Grundlage für die Entwicklung zu dienen.
## 3. Implementierung des Feedbacks
- [ ] Erstelle ein Feedback-Dokument für dich selbst, basierend auf einer
online Recherche zu möglichen weiteren implementierbaren features
- [ ] Passe das Konzept und das Design entsprechend deiner eigenen
Einschätzungen und möglichen Verbesserungsvorschlägen an.

## 4. Implementierung der Webapp
- [ ] Setze die geplanten Funktionen um.
- [ ] Achte auf sauberen und strukturierten Code.
- [ ] Führe regelmäßige Tests durch, um die Qualität zu gewährleisten.
## 5. Erstellung der Präsentation
- [ ] Bereite eine 10-minütige Präsentation vor, die die Kern-Features
deiner Webapp vorstellt.
- [ ] Erstelle eine Dokumentation, die die Technologieauswahl, das
Design, die Implementierung und die Tests der Webapp
beschreibt.
- [ ] Die Präsentation wird nicht vor einem Publikum präsentiert,
sondern dient als Dokumentation für den Kunden und das
Unternehmen.

# Anforderungen
## 1. Genutzte Technologien:
- Frontend:
	- React
	- React Redux
	- Redux Saga
	- React Router
	- Design Framework (z.B. Semantic UI React, Bootstrap React, Material UI) oder eigenes CSS auf dem Niveau von Semantic.
	- Cookies zur Speicherung von Sitzungsdaten.
- Backend:
	- Node.js
	- Express
	- MongoDB oder MySQL als Datenbank
	- JSON Web Tokens (JWT) für Authentifizierung
## 2. Funktionen:  
- Login-System mit Authentifizierung.  
- Kontaktformular zur Kommunikation.  
- Mindestens drei verschiedene Seiten (z.B. Startseite, Über uns, Kontakt).  
- Interaktionsmöglichkeiten für angemeldete Nutzer (z.B. Artikel erstellen, Kommentare hinterlassen).
## 3. Gestaltung: 
-  Ansprechendes und benutzerfreundliches Design.  
	-  Positivbeispiel: Velptec
	-  Negativbeispiel: Amis du Beauceron
## 4. Technische Anforderungen:  
- DSGVO-konforme Datenverarbeitung. 
- Sicherstellung der Datensicherheit durch Prävention möglicher Angriffe.
- Suchmaschinenoptimierung (SEO)
- Barrierefreiheit (Accessibility) für Nutzer mit Einschränkungen
## 5. Benutzererfahrung:  
- Schnelle Ladezeiten und Performance-Optimierung.  
- Mobile Responsiveness, damit die App auch auf mobilen Geräten gut funktioniert
## 6. Entwicklung:  
- Nutzung von Versionskontrollsystemen wie Git.  
- Einhaltung von Best Practices in der Code-Qualität und Struktur
## 7. Dokumentation:  
- Ausführliche Dokumentation des Codes und der Implementierungsentscheidungen.  
- Erstellung von API Dokumentationen für Backend-Dienste
## 8. Testing:  
- Durchführung von Unit Tests und Integrationstests
- Nutzung von Test Frameworks wie Jest oder Mocha
## 9. Deployment:
- Implementierung einer Continuous Integration/Continuous
Deployment (CI/CD)-Pipeline.
- Deployment der Webapp auf einem geeigneten Webserver
oder Cloud-Dienst.
## 10. Support und Wartung:
- Planung für zukünftige Updates und Verbesserungen.
- Implementierung von Monitoring-Tools zur Überwachung der
Webapp im Betrieb.

# Weitere Anmerkungen:
- Zeitmanagement: Plane deine Zeit sorgfältig und setze dir realistische Meilensteine.
- Fortbildung: Nutze Online-Ressourcen, Tutorials und Dokumentationen, um dein Wissen zu erweitern.
- Feedback einholen: Hole dir regelmäßig Feedback ein
- Testing: Teste deine Webapp auf verschiedenen Geräten und Browsern, um sicherzustellen, dass sie überall gut funktioniert.
